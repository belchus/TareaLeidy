# Ecommerce básico con Python y POO

Proyecto educativo que simula un ecommerce sencillo utilizando programación orientada a objetos.

## Funcionalidades

- Mostrar un menú principal.
- Mostrar los datos de un cliente.
- Mostrar productos disponibles.
- Modelar clientes y productos mediante clases.
- Utilizar archivos JSON para almacenar datos.

## Tecnologías

- Python
- Programación Orientada a Objetos
- JSON

## Cómo ejecutar

Desde la carpeta del proyecto:

```bash
python main.py
```

## Actividad para alumnos

Cloná este repositorio y personalizá el proyecto:

- Cambiá el nombre del ecommerce.
- Modificá los datos del cliente.
- Agregá o modificá productos.
- Personalizá los mensajes del menú.
- Agregá una nueva opción al menú.
